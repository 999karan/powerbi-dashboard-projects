# 📊 Power BI Dashboard Projects

**Power BI · DAX · Power Query · Data Modeling**

Four interactive, multi-page Power BI dashboards. Each project includes the `.pbix` file, dashboard screenshots, a written business report, and a README with key findings.

| # | Project | Domain | Highlights |
|---|---|---|---|
| 1 | [Retail Superstore Sales](1_Superstore_Sales_Retail) | Retail | Live MySQL connection, star schema, YTD / YoY / RANKX DAX, 46.9% YoY growth |
| 2 | [HR Attrition Analytics](2_HR_Attrition_Analytics) | HR | 1,470 employees, 16.1% attrition, decomposition tree |
| 3 | [Loan Approval & Risk](3_Loan_Approval_Finance) | Finance | 44,993 applications, 22.2% approval rate |
| 4 | [Marketing Campaign Analytics](4_Marketing_Campaign) | Marketing | 2,240 customers, 6 campaigns, response-rate drivers |

Open any `.pbix` in Power BI Desktop. The report in each `Report/` folder explains the data model, DAX measures and insights.
